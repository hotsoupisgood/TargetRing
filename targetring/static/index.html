targetring v1

A gene set, rings of evidence, and a drawer per gene. Nothing here is ranked or scored. Local only — nothing leaves this machine.

1. Differential expression table

Columns: gene symbol, logFC, adjusted p. CSV or TSV. Every row is either rendered or named in the drop ledger.
Accepted headers, as exported: DESeq2 log2FoldChange/padj, edgeR logFC/FDR, limma logFC/adj.P.Val. Positional guessing is never attempted.
Up to 60 genes. Above that the spokes are too narrow to read, so the table is capped by adjusted p and every excluded gene is named in the ledger.

2. Region

Affects exactly one ring — regional specificity, the region's median TPM divided by this gene's median across the GTEx panel. Genes below 1 TPM in the region are drawn no data rather than given a ratio: a ratio without a level is not a specificity statement.

3. Gene order around the circle

The default is the order of your submitted table, unchanged — you have usually already sorted it, and it is your measurement rather than a composite this app invented. Ordering by a single ring uses that one source's own number; genes with no value on it go last, as a visible block, never treated as the lowest value.

4. Threshold filters optional

One per line, as ring >= number or ring <= number, compared against the ring's own raw value — the number in values.csv, not a rank or a colour position. A filtered gene is removed from the plot and named in the drop ledger.
A threshold never drops a gene that has no data on that ring. It is kept and marked ~; otherwise filtering would quietly delete the under-studied genes instead of the ones that missed the threshold. Tick the box below to drop them anyway, and the figure will say that is what happened.
